# AROS Design System — MASTER.md

A-Share Research OS 前端设计系统。所有面板 / 颜色 / 字体 / 间距以本文件为准,
后端(FastAPI 桥接)与前端(React)共用同一套 token,保证视觉一致。

风格基调:**TradingView 暗色基底 × macOS 面板美学**
- 底色深而不过黑(`#0B0E14`),信息密集但分区清晰。
- 圆角面板 + 极轻毛玻璃点缀(非整片玻璃),避免纯工业感压抑。
- 所有数值**等宽字体**对齐(价格 / 涨跌幅 / 评分一列不抖动)。

## 1. 颜色 Tokens

### 背景 / 表面(从深到浅)
| Token | Hex | 用途 |
|---|---|---|
| `--bg-base` | `#0B0E14` | 全局最底背景 |
| `--bg-panel` | `#11151F` | 面板卡片背景 |
| `--bg-panel-2` | `#161B26` | 次级面板 / 表头 |
| `--bg-hover` | `#1C2330` | 行 hover / 按钮 hover |
| `--border` | `#232A38` | 面板描边 / 分隔线 |
| `--border-soft` | `#1A2030` | 弱分隔 |

### 文本
| Token | Hex | 用途 |
|---|---|---|
| `--text-hi` | `#E6EAF2` | 主文本 / 标题 |
| `--text` | `#AEB6C6` | 正文 |
| `--text-dim` | `#6B7587` | 次要 / 标签 / 单位 |

### 状态色(A 股惯例:红涨绿跌)
| Token | Hex | 用途 |
|---|---|---|
| `--up` | `#EF4444` | 上涨 / 阳线 / 利好 |
| `--down` | `#22C55E` | 下跌 / 阴线 / 利空 |
| `--up-dim` | `rgba(239,68,68,.14)` | 上涨底纹 |
| `--down-dim` | `rgba(34,197,94,.14)` | 下跌底纹 |
| `--accent` | `#3B82F6` | 强调 / 链接 / 激活态(中性蓝,不与涨跌冲突) |
| `--accent-2` | `#8B5CF6` | 次级强调(紫,用于 AI / 因子高亮) |
| `--warn` | `#F59E0B` | 告警 / 注意 |
| `--danger` | `#EF4444` | 错误(复用涨色,谨慎) |

> ⚠️ 涨跌色与欧美惯例相反。全站统一:正收益 / 上涨 = 红,负收益 / 下跌 = 绿。
> 任何图表(蜡烛图、进度条、表格)都遵守此规则,不混用国际惯例。

### 图表
- 蜡烛阳线(收盘≥开盘):`--up` (#EF4444)
- 蜡烛阴线(收盘<开盘):`--down` (#22C55E)
- 均线 MA5/MA20/MA60: `#F59E0B` / `#3B82F6` / `#8B5CF6`

- 网格线:`#1A2030`,轴线:`#2A3342`

## 2. 字体
- **数字 / 代码 / 指标值**:等宽 `ui-monospace, "JetBrains Mono", "IBM Plex Mono", "Fira Code", Menlo, Consolas, monospace`
- **UI 文本 / 标题**:无衬线 `system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 字号:面板标题 13px/600,正文 13px/400,小标签 11px/500 大写字母+字距,数字 13px 等宽。

## 3. 间距 / 圆角 / 阴影
- 间距基准 4px:面板内边距 16px,卡片间距 12px,列表行高 32–36px。
- 圆角:面板 12px,卡片/按钮 8px,标签 6px,头像 50%。
- 阴影:`0 1px 0 rgba(255,255,255,.02) inset, 0 8px 24px rgba(0,0,0,.35)`(轻,不浮夸)。
- 毛玻璃:面板背景 `rgba(17,21,31,.72)` + `backdrop-filter: blur(12px)`,仅顶栏/弹层使用。

│          ├──────────────────────────┬───────────────────┤

- 主体最大宽 1600px,居中;窄屏下右列换行到下方。

## 5. 组件规范
- **KPI 卡**:标签(11px dim)+ 数值(20px 等宽 hi)+ 涨跌幅(12px,红/绿)。
- **数据表**:表头 11px dim 大写;数值列右对齐等宽;涨跌单元格用 `--up/--down` 着色;hover 行 `--bg-hover`。
- **进度条**:轨道 `--bg-panel-2`,填充按语义(因子分高=accent-2,涨跌=up/down)。
- **徽标 badge**:圆形/方角小标,右上角数字(如 Alpha Radar 的 8)。
- **告警流**:左色条(涨红/跌绿/warn 黄),时间 11px dim,文案 12px text。
- **状态点**:绿=正常 / 黄=降级 / 红=异常,直径 8px 带微光。

## 6. 主题切换
- 提供深 / 浅两套 CSS 变量;默认深(TradingView 基底)。
- 浅色(macOS 风)为可选:`--bg-base #F5F6F8` / 面板 `#FFFFFF` / 文本 `#1A2030`,涨跌色**不变**(仍为红涨绿跌)。
- 通过 `<html data-theme="dark|light">` 切换,变量在 `:root` 与 `[data-theme=light]` 下定义。

## 7. 数据接入约定(桥接服务 → 前端)
- 所有金额/价格单位 **元(CNY)**;成交额以「亿元」展示时前端转换。
- 日期统一 ISO `YYYY-MM-DD`。
- NaN / None 序列化为 `null`,前端按「无数据」渲染。
- 接口前缀 `/api`,由前端在 `dev` 下代理到 `http://localhost:8000`。
- 无数据时返回 `{ "empty": true, "message": "请先运行 python main.py sync ..." }`,
  前端显示「演示数据」横幅 + mock 兜底,不报错白屏。
